# 未确认契约登记

任何条目在获得Markdown、后端示例报文、硬件协议或用户明确确认前，不进入运行逻辑。

执行原则：

- 没有确切证据的字段保持空值；
- 没有确切证据的动作保持禁用；
- 建议方案只能登记，不能进入HTTP、MQTT或串口报文；
- 后续获得证据时，同时记录来源、版本和对应源码修改；
- 一次性迁移脚本、诊断文件和临时工作流不得保留在交付分支。
