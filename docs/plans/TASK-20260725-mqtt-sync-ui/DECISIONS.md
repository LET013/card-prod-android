## D-007：状态上报结果文案

状态：证据约束

决定：

第一阶段只允许显示：

- `BLOCKED`：后端业务会话未认证；
- `NO_DATA`：没有可上报的真实卡槽；
- `SUBMITTED`：已交给现有客户端发送链；
- `FAILED`：客户端本地发送失败。

禁止显示“服务端确认成功”，因为现有负责人底层没有向客户端公开`statusReportResp.code/msg`。
