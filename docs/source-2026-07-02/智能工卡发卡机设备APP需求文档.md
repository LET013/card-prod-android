## 一、项目概述

### 1.1 项目名称

智能工卡发卡机设备APP（竖屏平板版）

### 1.2 项目背景

为满足企业或机构对工卡/工作卡的自助发放、归还、管理需求，开发一款运行于Android竖屏平板的发卡机控制APP，支持人脸识别、远程管理、卡位状态监控等功能。

### 1.3 适用设备

- Android竖屏平板
- 支持人脸识别摄像头
- 支持指纹识别模块（电容/光学指纹传感器）
- 支持有线/无线网络连接
- 支持串口通信（与小主板交互）

## 二、技术架构

### 2.1 架构分层

| 层次 | 技术方案 | 说明 |
|------|----------|------|
| UI 层 | Vue (uni-app) | 页面展示、用户交互 |
| 通信层 | Android Java | 通过 JsBridge 注入到 Vue |
| HTTP 通信 | Android Java | 通过 `window.android.http()` 调用 |
| Socket 通信 | Android Java | 通过 `window.android.socket()` 调用 |
| 串口通信 | Android Java | 通过 `window.android.serial()` 调用 |

### 2.2 JsBridge 接口清单

#### 2.2.1 HTTP 通信接口

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `http.post(url, data)` | URL, JSON数据 | Promise | 发送 HTTP POST 请求 |
| `http.get(url)` | URL | Promise | 发送 HTTP GET 请求 |

#### 2.2.2 Socket 通信接口

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `socket.connect(host, port)` | 主机, 端口 | boolean | 建立 TCP 连接 |
| `socket.send(data)` | 字符串/字节数组 | boolean | 发送数据 |
| `socket.onMessage(callback)` | 回调函数 | - | 接收消息回调 |
| `socket.disconnect()` | - | void | 断开连接 |

#### 2.2.3 串口通信接口

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `serial.open(config)` | 串口配置对象 | boolean | 打开串口 |
| `serial.close()` | - | void | 关闭串口 |
| `serial.send(hex)` | 十六进制字符串 | boolean | 串口发送数据 |
| `serial.onData(callback)` | 回调函数 | - | 串口数据接收回调 |

**串口配置对象示例：**
```javascript
{
  baudRate: 57600,    // 波特率
  dataBits: 8,        // 数据位 (5/6/7/8)
  stopBits: 1,        // 停止位 (1/1.5/2)
  parity: 'none'      // 校验位 ('none'/'odd'/'even')
}
```

#### 2.2.4 日志接口

| 方法 | 参数 | 说明 |
|------|------|------|
| `log.info(message)` | 日志内容 | 输出 Info 日志到 logcat |
| `log.warn(message)` | 日志内容 | 输出 Warn 日志到 logcat |
| `log.error(message)` | 日志内容 | 输出 Error 日志到 logcat |
| `log.debug(message)` | 日志内容 | 输出 Debug 日志到 logcat |

### 2.3 按钮交互效果规范

所有可点击按钮必须实现以下交互效果：

#### 2.3.1 按压态效果

| 效果 | CSS 实现 | 参数 |
|------|----------|------|
| 缩小动画 | `transform: scale(0.95)` | 按下时缩小 5% |
| 透明度变化 | `opacity: 0.8` | 按下时降低透明度 |
| 过渡时间 | `transition: all 0.15s ease` | 150ms 平滑过渡 |

#### 2.3.2 按钮样式示例

```scss
.btn {
  // 正常态
  transition: all 0.15s ease;

  &:active {
    transform: scale(0.95);
    opacity: 0.8;
  }

  &:disabled {
    opacity: 0.5;
    pointer-events: none;
  }
}
```

#### 2.3.3 禁用态

- 添加 `disabled` 属性
- 透明度降低至 50%
- 禁止点击事件穿透

## 三、功能需求

### 2.1 基础功能

| 模块    | 功能        | 说明               |
| ----- | --------- | ---------------- |
| 设备网络  | 支持有线/无线网络 | 支持静态IP配置，适用于内网环境 |
| 自启动   | 开机自启动APP  | 支持设置为系统自启动应用     |
| 定时开关机 | 设备定时开关机   | 开关机时间需间隔≥5分钟     |
| 应用管理  | 桌面图标管理    | 支持将应用图标拖动到桌面     |

### 2.2 APP配置功能（首次启动）

| 配置项     | 说明                                        |
| ------- | ----------------------------------------- |
| 波特率     | 默认57600                                   |
| 单组数量    | 默认10（小主板为2或10）                            |
| 总体数量    | 默认100卡槽                                   |
| 卡号解析    | 默认“转可见符”                                  |
| 轮询方式    | 默认“单组轮询”                                  |
| 设备ID    | 默认Android ID，可自定义                         |
| 服务器IP   | 支持配置IP及后缀路径                               |
| TCP端口   | 默认9009                                    |
| HTTP端口  | 默认8081                                    |
| 人脸识别阈值  | 默认0.9，可调低至0.6                             |
| 镜头旋转角度  | 默认270°（竖屏）                                |
| Token获取 | 可配置是否忽略                                   |
| 授权状态    | 红色表示未授权，支持在线授权（10年）                       |
| 人脸引擎激活  | 支持在线/离线激活，需填写APP\_ID、SDK\_KEY、ACTIVE\_KEY |
| 指纹识别模式  | 默认关闭，可开启指纹取卡功能                    |
| 指纹识别阈值  | 默认0.8，可调范围0.5-0.95                        |

### 2.3 主界面功能

| 功能    | 说明                             |
| ----- | ------------------------------ |
| 卡位展示  | 展示1\~100号卡位状态（空/充电中/已充满/故障等）   |
| 点击柜门号 | 显示卡位详细信息（卡号、电量、状态等）            |
| 管理员入口 | 点击ICON按钮，输入密码进入管理员模式（默认123456） |
| 开始使用  | 启动人脸识别或指纹识别流程（根据配置选择）            |
| 统计信息  | 显示空柜、充电中、已充满、故障等数量             |

### 2.4 管理员模式功能（需密码进入）

| 功能      | 说明            |
| ------- | ------------- |
| 一键弹卡    | 弹出所有卡片        |
| 退出管理员模式 | 按钮退出          |
| 不受服务器限制 | 管理员操作不依赖服务器参数 |

### 2.5 管理界面功能（管理员菜单）

| 功能   | 说明                 |
| ---- | ------------------ |
| 人脸注册 | 下发/注册人脸信息          |
| 人脸管理 | 查看已下发人员            |
| 指纹注册 | 下发/注册指纹信息          |
| 指纹管理 | 查看已注册指纹人员          |
| 单元管理 | 预留功能               |
| 历史管理 | 查看开门/还卡记录（仅供参考）    |
| 参数设置 | 调整人脸识别引擎参数         |
| 设备设置 | 修改设备ID、卡位数量等，需保存生效 |
| 激活引擎 | 激活人脸识别引擎           |
| 修改密码 | 修改管理员密码            |
| 重启应用 | 重启APP              |
| 系统授权 | 设备授权操作             |
| 返回首页 | 返回卡位列表             |

## 五、单板通信协议（串口通信）

### 5.1 协议基础说明

| 参数     | 规格                       |
| ------ | ------------------------ |
| 数据位    | 8位                       |
| 停止位    | 1位                       |
| 校验位    | 无                        |
| 波特率    | 57600                    |
| 通信模式   | 安卓屏为主机，充电单元板为从机          |
| 通信超时   | 100ms                    |
| 分机地址为0 | 广播模式，所有分机均解析该命令（适用于程序升级） |

### 5.2 协议帧格式说明

- **数据长度**：从该字节之后开始到CRC16之前的数据字节数
- **CRC16**：高字节在前，低字节在后，计算CRC校验从数据头一直到CRC16之前的数据进行校验

### 5.3 查询数据（功能码 0x01）

#### 5.3.1 查询命令（安卓发送）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 应答数据定义     | CRC  |
| ---- | ---- | ---- | ---- | ---- | ---------- | ---- |
| DDCC | \*\* | F0   | \*\* | 0x01 | 固定位 + 系统时间 | \*\* |

#### 5.3.2 查询返回（单板应答）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 正常返回值（12字节） | CRC  |
| ---- | ---- | ---- | ---- | ---- | ----------- | ---- |
| DDCC | \*\* | F0   | \*\* | 0x01 | 见下方字段说明     | \*\* |

**返回值字段说明：**

| 字节位置 | 字段    | 说明                                |
| ---- | ----- | --------------------------------- |
| 0    | 工作状态  | 0无效、1待机、2充电、3充电结束、4故障、5授权到期、6通信超时 |
| 1    | 在位状态  | 1开门状态、2关门状态                       |
| 2    | 卡状态   | 1有卡、2读卡错误（卡非法）                    |
| 3    | 卡状态变更 | 有卡↔无卡时为1，上位机轮询3次后清0               |
| 4-18 | 卡号    | 15字节卡号                            |
| 19   | 故障    | 按位定义（见下方）                         |
| 20   | 电压    | 50mV/bit                          |
| 21   | 电流    | 10mA/bit                          |

**故障按位定义：**

| 位    | 故障类型 |
| ---- | ---- |
| bit1 | 插卡错误 |
| bit2 | 过流   |
| bit3 | 门控故障 |
| bit4 | 过压   |
| bit5 | 欠压   |

### 5.4 开门控制（功能码 0x51）

#### 5.4.1 开门命令（安卓发送）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 固定位 + 开门控制标识 | CRC  |
| ---- | ---- | ---- | ---- | ---- | ------------ | ---- |
| DDCC | \*\* | F0   | \*\* | 0x51 | \*\*         | \*\* |

**开门控制标识：**

- 1：发卡开门
- 2：管理员开门
- 其余无效

#### 5.4.2 开门返回（单板应答）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 正常返回值（5字节）     | CRC  |
| ---- | ---- | ---- | ---- | ---- | -------------- | ---- |
| DDCC | \*\* | F0   | \*\* | 0x51 | 5A A5 5A A5 11 | \*\* |

**返回值说明：**

- 5A A5 5A A5 11：命令正常执行
- 5A A5 5A A5 12：命令未执行

### 5.5 LED亮度控制（功能码 0x52）

#### 5.5.1 LED控制命令（安卓发送）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 固定位 + 占空比 | CRC  |
| ---- | ---- | ---- | ---- | ---- | --------- | ---- |
| DDCC | \*\* | F0   | \*\* | 0x52 | \*\*      | \*\* |

**占空比设置范围：** 30\~100

#### 5.5.2 LED控制返回（单板应答）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 正常返回值（5字节）     | CRC  |
| ---- | ---- | ---- | ---- | ---- | -------------- | ---- |
| DDCC | \*\* | F0   | \*\* | 0x52 | 5A A5 5A A5 11 | \*\* |

### 5.6 读取版本号（功能码 0x53）

#### 5.6.1 读取版本命令（安卓发送）

| 起始标记 | 数据长度  | 主机地址 | 从机地址 | 功能码  | 固定位 + 01       | CRC  |
| ---- | ----- | ---- | ---- | ---- | -------------- | ---- |
| DDCC | 00 08 | F0   | \*\* | 0x53 | 5A A5 5A A5 01 | \*\* |

#### 5.6.2 版本号返回（单板应答）

| 起始标记 | 数据长度  | 主机地址 | 从机地址 | 功能码  | 正常返回值                                           | CRC  |
| ---- | ----- | ---- | ---- | ---- | ----------------------------------------------- | ---- |
| DDCC | 00 0B | F0   | \*\* | 0x53 | 5A A5 5A A5 + 硬件主版本号 + 硬件从版本号 + 软件主版本号 + 软件次版本号 | \*\* |

**版本号范围：** 主版本号 1\~100，从版本号 0\~9

### 5.7 单板升级使能（功能码 0x80）

| 起始标记 | 数据长度 | 主机地址 | 从机地址   | 功能码  | 命令序列（8字节）               | CRC  |
| ---- | ---- | ---- | ------ | ---- | ----------------------- | ---- |
| DDCC | \*\* | F0   | 0或\*\* | 0x80 | 5A 5A A5 A5 A5 A5 5A 5A | \*\* |

**说明：**

- 从机地址为0时：广播模式，无应答
- 从机地址非0时：单板地址模式

### 5.8 单板升级程序传输（功能码 0x81）

| 起始标记 | 数据长度 | 主机地址 | 从机地址 | 功能码  | 数据长度标识         | 帧序号  | 帧序号反码 | 数据   | CRC  |
| ---- | ---- | ---- | ---- | ---- | -------------- | ---- | ----- | ---- | ---- |
| DDCC | \*\* | F0   | 0    | 0x81 | 1:128 / 2:1024 | \*\* | \*\*  | \*\* | \*\* |

### 5.9 通信协议命令汇总表

| 功能码  | 命令名称    | 方向    | 说明              |
| ---- | ------- | ----- | --------------- |
| 0x01 | 查询数据    | 安卓→单板 | 查询卡位状态信息        |
| 0x01 | 返回查询结果  | 单板→安卓 | 返回工作状态、卡号、电压电流等 |
| 0x51 | 开门控制    | 安卓→单板 | 发卡开门/管理员开门      |
| 0x51 | 返回开门结果  | 单板→安卓 | 执行成功/失败         |
| 0x52 | LED亮度控制 | 安卓→单板 | 设置占空比30\~100    |
| 0x52 | 返回控制结果  | 单板→安卓 | 执行成功/失败         |
| 0x53 | 读取版本号   | 安卓→单板 | 读取硬件/软件版本       |
| 0x53 | 返回版本号   | 单板→安卓 | 返回版本信息          |
| 0x80 | 升级使能    | 安卓→单板 | 使能单板升级模式        |
| 0x81 | 升级程序传输  | 安卓→单板 | 传输固件数据          |

### 9.4 组件实现要求

```json
    {

      "style": {
        "navigationStyle": "custom",
        "navigationBarTitleText": "标题"
      }
    }
  ]

```

#### 9.4.2 必须使用自定义 TabBar

**原因**: UniApp 原生 TabBar 不支持 CSS 样式适配

**配置方式**: `pages.json` 中移除 `tabBar` 配置，使用自定义组件

### 9.5 CSS 媒体查询断点

```scss
/* 手机 (< 600px) */
@media screen and (max-width: 599px) {
  /* 手机样式 */
}

/* 平板 (>= 600px) */
@media screen and (min-width: 600px) {
  /* 平板样式 */
}

/* 超大平板 (>= 800px) */
@media screen and (min-width: 800px) {
  /* 超大平板样式 */
}
```

### 9.6 注意事项

1. **使用 rpx 单位**: rpx 是 UniApp 的响应式单位，可以自动适配不同屏幕
2. **避免固定像素**: 禁止在样式中使用 px 单位，应使用 rpx
3. **必须使用自定义导航**: 原生导航栏无法适配
4. **必须使用自定义 TabBar**: 原生 TabBar 无法适配
5. **考虑安全区域**: 使用 `env(safe-area-inset-bottom)` 处理全面屏底部
6. **测试多个分辨率**: 开发完成后需要在不同分辨率设备上测试
