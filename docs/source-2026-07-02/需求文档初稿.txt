智能发卡机系统 - 需求与通信协议文档
一、需求文档
1. 项目概述
本项目为智能发卡机系统，包含Android终端APP与后台管理系统。系统通过串口控制硬件卡位，通过HTTP和Socket与后台通信，实现卡位管理、人员认证（人脸/指纹）、远程控制等功能。

2. 系统架构
终端APP：运行于发卡机Android设备，负责UI交互、硬件控制、生物识别、与后台通信。

后台管理系统：Web端管理平台，负责终端管理、员工管理、生物特征库管理、指令下发与日志监控。

通信方式：

HTTP：用于取还卡上报、设备激活、配置拉取等请求。

Socket长连接：用于人员同步、远程指令、实时状态上报。

二、APP与后台通信协议文档
1. 概述
HTTP接口：短连接，用于业务上报、设备激活、配置拉取等。

Socket长连接：保持在线，用于实时指令下发与状态上报。

2. HTTP接口定义
2.1 设备激活接口
2.1.1 获取注册码（APP → 后台）
设备首次启动或重置后，通过设备ID向后台申请注册码。

URL：POST /api/v1/device/activate

请求体：

json
{
  "deviceId": "DEV001",
  "mac": "AA:BB:CC:DD:EE:FF",
  "model": "FJ-100",
  "version": "1.0.0"
}
响应：

json
{
  "code": 0,
  "msg": "success",
  "data": {
    "registerCode": "ABC123XYZ",
    "status": "ACTIVATED" | "PENDING_APPROVAL",
    "expireTime": 1735689600000
  }
}
2.1.2 激活验证（APP → 后台）
用户输入注册码后，APP向后台验证注册码有效性。

URL：POST /api/v1/device/verify

请求体：

json
{
  "deviceId": "DEV001",
  "registerCode": "ABC123XYZ"
}
响应：

json
{
  "code": 0,
  "msg": "success",
  "data": {
    "valid": true,
    "token": "session_token",
    "expireTime": 1735689600000,
    "deviceName": "一楼大厅发卡机"
  }
}
2.1.3 设备授权状态查询（APP → 后台）
APP定期查询设备授权状态，用于判断是否允许正常使用。

URL：GET /api/v1/device/auth/status?deviceId=DEV001

响应：

json
{
  "code": 0,
  "msg": "success",
  "data": {
    "isAuthorized": true,
    "authorizedUntil": 1735689600000,
    "daysRemaining": 365,
    "features": ["FACE", "FINGER", "REMOTE_OPEN"]
  }
}
2.1.4 在线授权续期（APP → 后台）
URL：POST /api/v1/device/auth/renew

请求体：

json
{
  "deviceId": "DEV001",
  "token": "session_token"
}
响应：

json
{
  "code": 0,
  "msg": "success",
  "data": {
    "newExpireTime": 1767225600000,
    "daysAdded": 365
  }
}
2.2 取卡/还卡上报
URL：POST /api/v1/card/event

请求体：

json
{
  "deviceId": "DEV001",
  "cardNo": "123456",

  "authType": "FACE" | "FINGER" | "ADMIN"
}
响应：

  "msg": "success"
}

3. Socket长连接协议
3.1 基础协议
3.1.1 登录请求（APP → 后台）
json
{
  "cmd": "login",
  "deviceId": "DEV001",
  "registerCode": "ABC123",
  "version": "1.0.0"
}
3.1.2 登录响应（后台 → APP）
json
{
  "cmd": "loginResp",
  "code": 0,
  "msg": "success",
  "token": "session_token"
}
3.1.3 心跳（APP → 后台，间隔30s）
json
{
  "cmd": "heartbeat",
  "deviceId": "DEV001",
  "timestamp": 1700000000000
}
后台响应：

json
{
  "cmd": "heartbeatResp",
  "code": 0,
  "serverTime": 1700000000000
}
3.1.4 登出（APP → 后台）
json
{
  "cmd": "logout",
  "deviceId": "DEV001"
}
3.2 指令下发协议（后台 → APP）
3.2.1 同步人员与生物特征
json
{
  "cmd": "syncUser",
  "data": {
    "userId": "U001",
    "name": "张三",
    "faceFeature": "base64_face_data",
    "fingerFeature": "base64_finger_data",
    "action": "ADD" | "DELETE" | "UPDATE"
  }
}
APP响应：

json
{
  "cmd": "syncUserResp",
  "code": 0,
  "msg": "success"
}
3.2.2 远程发卡/开门指令
json
{
  "cmd": "remoteOpen",
  "slotId": 5,
  "authType": "ADMIN",
  "operatorId": "admin001"
}
APP响应：

json
{
  "cmd": "remoteOpenResp",
  "code": 0,
  "slotId": 5,
  "status": "OPENED"
}
3.2.3 查询实时状态
json
{
  "cmd": "queryStatus",
  "slotId": -1

APP响应：

json

  "cmd": "statusResp",

    {
      "slotId": 1,
      "status": "OCCUPIED",
      "cardNo": "123",

      "current": 0.5

  ]
}
3.2.4 远程一键弹卡
json
{

APP响应：

json

  "code": 0,
  "msg": "success",
  "ejectedCount": 10

3.2.5 重启APP
json
{
  "cmd": "restartApp",
  "delayMs": 3000

APP响应：

json
{
  "cmd": "restartAppResp",
  "code": 0,

4. 错误码定义
错误码	说明
0	成功
1001	注册码无效或已过期
1002	Token过期或无效
1003	设备未授权
1004	设备已被禁用
1005	设备不存在
1006	激活码已被其他设备使用
2001	人员已存在
2002	特征数据错误或为空
2003	人员不存在
3001	卡位不存在
3002	卡位被占用
3003	卡位已空闲
4001	硬件操作超时
4002	硬件未响应
4003	串口通信失败
5001	人脸引擎未激活
5002	指纹引擎未初始化
6001	数据库操作失败
9000	系统内部错误

6. 通用数据格式说明
6.1 卡位状态枚举
状态值	说明
EMPTY	空位
OCCUPIED	有卡（未充电）
CHARGING	充电中
FULL	已充满
FAULT	故障
6.2 认证类型枚举
类型值	说明
FACE	人脸识别
FINGER	指纹识别
ADMIN	管理员操作
REMOTE	远程指令
6.3 时间格式
所有时间戳统一使用 毫秒级Unix时间戳（13位数字）。

示例：1700000000000 表示 2023-11-14 22:13:20 UTC。
