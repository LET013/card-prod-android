# 响应式适配规范

## 基本原则

800×1200 仅用于对照设计稿，不是运行时固定画布。

禁止：

- 固定根容器宽高为 800×1200
- 强制 2:3 宽高比
- 对整页使用 `transform: scale()`
- 通过大量绝对坐标复刻页面
- 因屏幕比例差异产生黑边

## 实现方式

- 根页面使用 WebView 实际可用宽高
- 使用 Flex、CSS Grid、百分比和 `minmax()`
- 使用 `clamp()` 为字号、间距和控件尺寸设置上下限
- 使用 `100dvh`，同时兼容不支持动态视口单位的环境
- 表单高度不足时允许内容区纵向滚动
- 键盘弹出后保持当前输入项可见
- 安全区使用 `env(safe-area-inset-*)`
- 触控目标维持可操作的最小尺寸，不通过整页缩小强行塞入屏幕

## 页面结构约束

响应式适配允许调整间距和列宽，但应维持业务结构：

- 品牌标题与卡柜号为两行
- 配置页主要输入保持双列关系
- 功能参数首行独占，其余为左右两列
- 起始符与结尾符保持左右布局
- 状态行占满可用宽度
- 管理菜单根据可用宽度自适应列数
- 卡位网格根据总数、屏幕宽度和最小卡片宽度计算列数

## 参考断点

断点仅用于微调，不用于切换到完全不同的页面设计：

```scss
@media (max-width: 599px) { }
@media (min-width: 600px) and (max-width: 899px) { }
@media (min-width: 900px) { }
```

## 验证尺寸

至少测试：

- 800×1200 设计对照视口
- 800×1280 终端视口
- 600×960 较小竖屏
- 1080×1920 高分辨率竖屏

检查无横向溢出、无控件重叠、无固定画布黑边、键盘可正常避让。
