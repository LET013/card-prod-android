## 2026-07-21

### 创建独立串口调试项目
- 路径: `/serial-debug/`
- 用途: 专门测试工作卡 Android APP 与单板通信协议 V1.5
- 复用父项目的 gradlew 和 SDK 配置
- **AGP**: 8.4.0 (与父项目一致)
- **依赖**: `io.github.xmaihh:serialport:2.1.1` + Material Components
- **串口库注意**: 版本 2.1.1 的数据回调方法是 `onDataReceived(ComBean)` 而非 `onDataBack`

### 项目结构
```
serial-debug/
├── app/src/main/java/com/xingyao/serialdebug/
│   ├── MainActivity.java           # 入口
│   ├── SerialDebugActivity.java    # 调试面板
│   ├── protocol/WorkCardProtocol.java  # 协议编解码
│   └── serial/SerialManager.java   # 串口封装
└── app/src/main/res/layout/
    ├── activity_main.xml
    └── activity_serial_debug.xml
```

### 调试面板功能
- 串口配置: 路径 + 波特率 + 连接/断开
- 协议指令: 查询、开门(普通/管理员)、LED、版本
- 原始 HEX 发送
- 自动轮询 (2秒/次)
- 带时间戳的实时日志 (上限500行)
- 深色主题终端风格 UI
