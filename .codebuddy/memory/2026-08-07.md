# 2026-08-07

## 串口轮询状态更新延迟优化

**问题**: 取卡后状态更新延迟严重，约 1-1.5 分钟才更新到最新状态。

**根因**: 
1. `SlotStateManager` 默认 60s 定时批量推送，单槽更新后不即时通知前端
2. 轮询 tick 间隔 350ms，100 槽轮询一周需 35s

**修复**:
1. `handleQueryResponse()` 中在 `updateSlot` 后立即调用 `notifySlot(slotStatus)`，不再等待 60s 批量推送
2. `POLL_TICK_INTERVAL_MS`: 350ms → 200ms，轮询一周从 35s 降至 20s

**效果**: 最坏延迟从 ~95s (35s polling + 60s push) 降至 ~20s (20s polling + immediate notify)
